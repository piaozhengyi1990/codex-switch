Codex 模型切换器 使用说明（v1.0.0）

【这是什么】
  把 Codex 切换到国内大模型（DeepSeek / 通义千问 / 智谱 GLM / Kimi / 火山方舟）
  的图形化工具。只接管"用哪个模型"这几个配置项，Codex 的其他原生功能一律不动。

【首次运行】
  1. 双击 CodexSwitch.exe，第一次会弹 Windows SmartScreen 蓝色提示。
     点"更多信息" -> "仍要运行"即可（本程序没有代码签名证书，属于正常现象）。
  2. 如果杀毒软件提示，选择"信任 / 允许"。
  3. 不需要安装 Python，单个 exe 文件双击即可。

【怎么切换模型】
  1. 打开"切换模型"页，左侧选择服务商
  2. 选择模型（火山方舟要填真实的推理接入点 ID，ep- 开头）
  3. 粘贴 API Key，点"保存 Key"
  4. 点"预览更改"先看 diff，确认无误再点"应用切换"
  5. 完全退出 Codex（桌面端和终端都要关掉）再重新打开 —— 这一步不做不生效

【怎么切回去】
  "切回 Codex 原生内置模型"：只撤销本工具接管的字段，回到 Codex 默认状态
  "还原原始快照"：回到本工具第一次运行前的原始 config.toml + models.json
  "备份与还原"页：切换前会自动备份，最多保留 10 份，可任选一份还原

【配置自检】
  "配置自检"页会跑 13 项检查：TOML 是否合法、wire_api 是否残留 chat、
  base_url 是否正确、环境变量是否写入、模型是否在目录里……有红字就照详情修。
  还没切换过时，相关项显示灰字"尚未接入（点应用切换后自动生成）"，
  这是中性提示、不算失败，不会标红。

【API Key 存在哪里】
  1. Windows 凭据管理器（系统加密，界面上永远掩码显示，可一键清除）
  2. 同时写入当前用户的环境变量 —— Codex 只认环境变量，这一步躲不掉
  不会写进 config.toml 明文，除非你在"设置"页手动打开那个开关（会先弹风险提示）。
  点"测试 Key"会发一个只读请求验证 Key 是否有效：
  Key 被拒绝会红字提示；只是连不上网络则提示"网络不通"，不算失败。

【常见问题】
  Q: 切换成功了但 Codex 没变？
  A: 没有完全退出重启。桌面端要彻底退出，终端要新开一个。

  Q: 日志在哪？
  A: 界面下方"操作日志"实时显示；文件在 %LOCALAPPDATA%\CodexSwitch\logs\switch.log
     （按 Windows 规范放用户数据目录，可轮转，出问题时把它发给维护者即可）。

  Q: Codex 桌面端第一次打开要登录，是不是得先登录才能用本工具？
  A: 那个登录引导是 Codex 自己的，与本工具无关。本工具的切换不依赖登录态
     （命令行实测：没有 auth.json 也能用环境变量里的 Key 正常发请求）。
     桌面端按它自己的流程登录后再切换即可，登录与切换互不影响，
     本工具也不碰 Codex 的登录信息。

  Q: 改坏了怎么恢复？
  A: "备份与还原"页选最近一份还原；或用"还原原始快照"回到最初状态。

【提示】
  内部使用，禁止外传与商业使用。
  界面底部会显示配置目录，出问题时把 ~/.codex/config.toml 发给维护者即可。
